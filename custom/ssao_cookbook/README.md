# Cookbook SSAO — minimal port

Source: [PacktPublishing/3D-Graphics-Rendering-Cookbook-Second-Edition](https://github.com/PacktPublishing/3D-Graphics-Rendering-Cookbook-Second-Edition)
at commit `6777c3e`, files `Chapter10/04_SSAO/src/SSAO.comp`,
`Chapter10/04_SSAO/src/combine.frag`, and `data/shaders/Blur.comp` (MIT).

This is a standalone compute-only port. It does **not** include Bistro,
LightweightVK, ImGui, MSAA, or a window. It loads a fixed raw fixture, runs
SSAO -> separable bilateral blur -> combine, reads the final RGBA8 image back,
and writes a PPM.

## Fixes vs. the book

- The 4x4 rotation texture is tiled with
  `(mod(xy, 4) + 0.5) / 4` instead of `xy / 4`, which clamped to one texel.
- The rotation plane is decoded and normalized:
  `normalize(texture(rot, uv).xyz * 2.0 - 1.0)`.
- The synthetic fixture uses `radius=0.10`, `distScale=10.0`,
  `attScale=1.0` (all inside the cookbook UI ranges) so the cookbook
  occlusion curve is visible on the fixed scene. The book defaults are
  `radius=0.03`, `distScale=1.0`, `attScale=1.5`.

## Build

```bash
cmake -S . -B build
cmake --build build --target ssao_cookbook -j"$(nproc)"
```

The binary is written to `bin/ssao_cookbook`.

## Run

```bash
VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/lvp_icd.json \
  ./bin/ssao_cookbook ssao.ppm
```

The output is 512x512 P6 PPM. Two consecutive runs are byte-identical.

## Fixture

`fixtures/` contains the fixed raw inputs:

- `depth.r32f` — 512x512 float32 Vulkan depth
- `color.rgba8` — 512x512 RGBA8 scene color
- `rotation.rgba8` — 4x4 RGBA8 rotation pattern
- `params.txt` — the exact parameters used by the harness

They are generated by `fixtures/gen_fixtures.py`. The same raw files are used
by the Java parity test, so both renderers consume byte-identical inputs.
