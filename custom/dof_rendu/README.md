# Rendu DOF — minimal port

Source: [kosua20/Rendu](https://github.com/kosua20/Rendu) @ `31dfb8a`,
`resources/common/shaders/screens/dof-coc.frag`,
`dof-gather.frag`, `dof-composite.frag` (MIT).

This is a standalone compute-only port. It does **not** include the Rendu
engine, Bistro, LightweightVK, ImGui, MSAA, or a window. It loads a fixed
512x512 color/depth fixture, runs CoC -> spiral gather -> composite, reads the
final RGBA16F image back, and writes a PPM.

## Fixture

A 512x512 checkerboard split into two depth planes:

- left half: in focus at `z=2`
- right half: defocused at `z=10`
- `zNear=0.1`, `zFar=100`
- `focusDist=2.0`, `focusScale=10.0`

Raw inputs: `fixtures/color.rgba16f` and `fixtures/depth.r32f`, generated by
`fixtures/gen_fixtures.py`. The same raw files are used by the Java
`RzCppDofParityTest`.

## Build

```bash
cmake -S . -B build
cmake --build build --target dof_rendu -j"$(nproc)"
```

The binary is written to `bin/dof_rendu`.

## Run

```bash
VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/lvp_icd.json \
  ./bin/dof_rendu dof.ppm
```

Two consecutive runs are byte-identical:

```text
f2c24ea45fd0138b270007c1d0229ba837539683a792608bf413368375618e49
```

`screenshot.png` is the verified 512x512 result: the left checkerboard is
sharp, the right plane is defocused.
